# Blog Writing Editing

## Workflow

1. Read `../../../docs/BLOG_WRITING_GUIDE_FOR_CODEX.md` completely before doing blog writing or editing work.
2. Apply the Hugo content conventions in `../../../agents.md` for page bundles, frontmatter, local images, table of contents settings and compile testing.
3. Keep the guide as the source of truth for blog voice, structure, editing, evidence, bullets, maintenance and prose mechanics.
4. Do not duplicate or override the guide in this skill. If reusable blog writing guidance changes, update the guide instead.

## Output Rules

- For repo edits, make the smallest useful change that satisfies the blog task, then run the compile test from `agents.md`.
- For draft only requests, follow the guide's output contract for title options, suggested tags, excerpt or meta description and draft body.
- Do not add social media distribution guidance unless the user explicitly asks for it.
